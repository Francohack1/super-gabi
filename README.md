# Super Gabi

Lista del súper compartida para la casa (Mercadona y Lidl), instalable como app en el celular.

- Abrí https://francohack1.github.io/super-gabi/ en Chrome y tocá **Instalar**.
- Sin cuentas: la casa se comparte con un link secreto (Ajustes → Invitar).
- Datos en Supabase (proyecto `super-gabi`, plan gratis), aislados por casa con RLS.
- Comidas con IA usando Gemini (clave gratis, guardada sólo en cada teléfono).
- Funciona sin señal: los cambios se guardan y se suben al volver la conexión.
